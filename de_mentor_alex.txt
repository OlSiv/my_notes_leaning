dbeaver - универсальный инструмент для работы с различными базами данных

всегда скачивать новые драйвера

третья строка сверху - первая слева вкладка "Проекты" (Projects)
--
SELECT version();
----

--
SELECT 1;
select 2

select 3
----
- пустая строка в DBeaver тоже считается как разделитель команд, но лучше всегда ставить точку с запятой 

можно выделить кусок кода и выполнить (тут выделить без -- в начале строки) -
--
-- select 4;
----

-- (две черты) - это однострочный комментарий

/*
select ...
FROM ...
WHERE ...
*/
- это многострочный комментарий 

CTRL + ENTER - выполнить SQL-запрос (или можно нажать кнопку)

CTRL + / - закомментировать несколько выделенных строк 

зажав CTRL можно выделить несколько разных строк 

переключить на режим просмотра - клавиша TAB - колонки станут строками, а строки колонками 

можно для паралельного  выполнения второго выражения использовать клавишу - оранжевый треугольник с плюсом, либо CTRL + \

поставить темную тему - Окна - Параметры - Интерфейс - Внешний вид - там найти и поставить тему Dark - потом перезапустить программу

внизу где знак шестеренки можно поставить максимальный размер выборки - количество выводимых строк (типа limit)

там же справа от окна с числом есть кнопка - посчитать общее количество строк

нажав на название таблицы в БД в колонке слева можно изучить её свойства

и тамже можно посмотреть диаграмму (как таблицы связанны между собой) но это работает не для всех видов баз данных 

можно создавать шаблоны (иконка где синий кубик лежит на двух синих кубиках такого же размера)

как сделать шаблон самому - 
Окна - Параметры - Редакторы - Редактор SQL - Templates 

автоматическое форматирование кода - 
- выделить всё - CTRL + A
- форматирование - CTRL + SHIFT + F

Автоформатирование можно настраивать - 
Окна - Параметры - Редакторы - Редактор SQL - Форматирование 

там установить - 
- регистр ключевых слов - Upper
- размер отступа - 2 
- использовать пробелы вместо табов - вкл (вместо таба будет 4 пробела)
- вставлять перевод строки перед закрывающейся скобкой - вкл
- вставлять перевод строки перед запятыми - вкл 
- вставить разделители в пустые строки - вкл 

экспорт и импорт данных - 
- экспортировать можно в CSV, JSON и т.д.
- также можно и импортировать (в столбце Transform можно задать трансформацию)
чтобы не было конфликтов, при загрузке данных можно установить метод замены - ON CONFLICT DO UPDATE SET 
- можно делать экспорт в другие базы данных 

можно создавать, сохранять и запускать задачи - стрелочка вниз справа от иконки где синий кубик лежит на двух синих кубиках такого же размера
