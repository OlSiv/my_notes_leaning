Обнови main и создай ветку задачи - 
Переключись на main, получи последние изменения и создай отдельную ветку. Начни имя с ключа Jira: это связывает код с задачей и упрощает поиск истории.
- Не выполняй учебную работу прямо в main.
- Одна ветка должна решать одну задачу.
- Перед созданием следующей ветки снова обнови main.

--
git checkout main
git pull
git checkout -b DEIN-7809-short-title
git branch --show-current
----



Проверь содержимое и изменения - 
Открой созданный файл, выполни или проверь решение и сохрани его. 
Затем в терминале посмотри git status и git diff. 
В diff должны быть только изменения текущей задачи.
- Красные строки удалены, зелёные добавлены.
- Если видишь случайный файл, не добавляй его в commit и при необходимости внеси в .gitignore.
- Исправь форматирование до фиксации истории.

--
git status
git diff
----



Добавь файлы и создай осмысленный commit -
Добавь только проверенные файлы, создай commit с ключом задачи и коротким описанием результата. После commit снова выполни git status — рабочее дерево должно быть чистым.
- Не используй сообщения «fix», «work» или «final» без контекста.
- Ключ DEIN-47 в начале связывает commit с Jira.
- Если забыл файл, добавь отдельный commit; не переписывай общую историю без необходимости.

--
git add path/to/file.sql
git commit -m "DEIN-47 add customer report query"
git status
----



Отправь ветку в Gitea -
При первом push укажи upstream. После выполнения команда выведет ссылку на создание merge request. Обнови страницу репозитория Gitea и проверь, что ветка появилась.
- Push не переносит ветку в main и не завершает задачу.
- Следующие изменения в этой ветке отправляются обычным git push.
- Если push отклонён, прочитай сообщение: чаще всего требуется авторизация или обновление удалённой ветки.

--
git push -u origin DEIN-47-short-title
----
